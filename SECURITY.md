# Security Policy

This repository holds the skills listed on [seoskills.sh](https://seoskills.sh).
To report a security issue with a skill or with the site, please report it
privately, not in a public issue.

## Reporting a vulnerability

Open a private vulnerability report on this repository:
https://github.com/seoskills-sh/catalog/security/advisories/new

Include enough detail to reproduce the issue. If it concerns a skill listed on
seoskills.sh, include the skill URL.

## What happens next

- We acknowledge your report within 1 business day.
- If a listed skill is a credible risk, we take it down promptly. A removed
  skill returns a 404 and drops out of the catalog, the API, the MCP endpoint
  and the discovery index, so it can no longer be installed from seoskills.sh.
- We tell the skill author, and re-list the skill only after a fixed version
  passes review.
